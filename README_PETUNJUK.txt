MATEMATIKA KELAS III SD/MI — BAB 1, 34 HALAMAN
PENDAMPING AKADEMIK

ISI PAKET
- index.html : buku digital interaktif dengan 34 halaman, daftar isi, latihan, PjBL, evaluasi otomatis, dan pembahasan.
- README_PETUNJUK.txt : panduan penggunaan.

CARA MEMBUKA
1. Klik dua kali index.html agar terbuka di Chrome/Edge.
2. Gunakan tombol Sebelumnya/Selanjutnya atau daftar isi kiri.
3. Gunakan tombol Cetak jika perlu mencetak seluruh materi.
4. Jawaban evaluasi disimpan sementara di browser yang sama melalui localStorage (tanpa server).

CARA DI GITHUB PAGES
1. Buat folder misalnya matematika/kelas-iii/bab-1/ dalam repo GitHub Pages.
2. Upload index.html ke folder tersebut.
3. Akses https://USERNAME.github.io/NAMA-REPO/matematika/kelas-iii/bab-1/
4. Tampilkan dalam Blogger memakai iframe:
   <iframe src="URL-GITHUB-PAGES-ANDA" width="100%" height="900" style="border:0;border-radius:16px" loading="lazy" title="Matematika Kelas III Bab 1"></iframe>
   Ganti URL-GITHUB-PAGES-ANDA dengan tautan yang benar sesudah upload.
